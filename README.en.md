## Who am I?
<p>I'm a vmplayer (I don't plan on revealing my real name at the moment), a third-year high school student, I enjoy learning and also some challenges.</p>
<p>Actually, I'm studying HTML, CSS3, and JavaScript. I don't have much money to buy courses or invest in something better, so I like to just read the documentation or watch some YouTube videos on these topics.</p>
<p>In 2024, I was a student in a Digital Game Development course where I learned to use graphics engines like Unity, some more advanced ones like Unreal Engine, and some more basic ones like Godot. There, I also learned Programming Logic and C#.</p>
<p>From a young age, I've always had a great interest in games. I've always enjoyed playing and immersing myself in different worlds and stories. From there, I started creating everything I imagined. Currently, I'm on my way to becoming a game developer.</p>
